# 新竹縣關西鎮太平國民小學 72 週年校慶 — 貴賓簽到系統

本系統採用 **GitHub Pages 前端 + Google Apps Script (GAS) 後端** 架構，已整合太平國小校徽與 72 週年校慶 41 位貴賓名單。

---

## 📁 檔案說明

- `index.html`：接待桌貴賓簽到系統（含分類篩選、即時搜尋、一鍵簽到、代理/助理備註、新增現場貴賓）
- `mc.html`：司儀即時貴賓看板（依簽到時間由新到舊排序，每 5 秒自動同步）
- `shared.js`：共用模組與 41 位預設貴賓資料（未綁定 GAS 時可於本機展示測試）
- `Code.gs`：Google Apps Script 後端程式（內含一鍵初始化 41 筆名單函式 `initTaiping72Data`）
- `太平國小_校徽.png`：太平國小校徽圖檔
- `太平國小72校慶貴賓匯入資料.xlsx`：整理好的 41 筆貴賓名單與分類設定備份檔

---

## 🚀 3 步驟快速部署

### 步驟 1：更新 Google 試算表與 GAS 後端
1. 開啟您的 Google 試算表，點選上方 **「擴充功能」→「Apps Script」**。
2. 清空原有程式碼，將本資料夾中的 [`Code.gs`](./Code.gs) 全選複製貼上並儲存（`Ctrl + S`）。
3. 在編輯器上方函式下拉選單選擇 **`initTaiping72Data`**，點選 **「執行」**（首次會要求核准授權）。執行完成後，試算表會自動清空舊範本資料，並建置好太平國小 41 位貴賓與 6 項分類！
4. 點選右上角 **「部署」→「新增部署作業」**：
   - 類型選擇 **「網頁應用程式」**
   - 執行身分：**「我」**
   - 誰可以存取：**「所有人 (Anyone)」**
5. 複製產生的 `/exec` 網址。

### 步驟 2：上傳前端至 GitHub Pages
將 `index.html`、`mc.html`、`shared.js`、`太平國小_校徽.png` 上傳至 GitHub Repository 並啟用 GitHub Pages。

### 步驟 3：綁定雲端連線
開啟 `index.html` 點選右上角 **「⚙️ 連線設定」**，貼上步驟 1 取得的 `/exec` 網址並儲存，或直接開啟 `index.html?gas=您的GAS網址` 即可多台設備同步使用（司儀台開啟 `mc.html?gas=您的GAS網址`）。
